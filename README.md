# 恩尼格玛密码机 · Enigma I 模拟器

一个模拟二战德军 Enigma I（Wehrmacht 三转子型）工作原理的网页工具：木箱 + 金属面板风格，真机三排灯板/键盘布局，零依赖纯静态实现，打开 `index.html` 即用。

![截图](docs/screenshot.png)

上图为初版截图；当前版本已更新真机键盘布局，并增加设置状态和结果提示。

## 功能

- **逐键加密**：点击键帽或直接敲物理键盘，每按一键转子先机械步进、灯板亮出密文字母，与真实机器流程一致
- **密钥设置**：5 个转子（I–V）任选 3 个及排列、环设置（Ringstellung）、起始位置、反射板（UKW-A/B/C）、插线板（理论上至多 13 对；二战常见配置为 10 对，非法配置在应用时报错）
- **史实细节**：中轮缺口双步进（double-step）、反射板互逆性质（字母永不加密成自身、加解密同流程）、真机三排布局 `QWERTZUIO / ASDFGHJK / PYXCVBNML`
- **手拧转子**：点击顶部转子窗口可像真机一样直接转动转子设定位置
- **整段文本**：使用已应用的密钥和起始位置，每次从头处理，不改变逐键状态；密文粘回运行可还原 A–Z 文本，输出按电文惯例 5 字一组
- **明密文对照记录**：像真机旁的记录员一样按 5 字组抄写输入与输出
- **操作兼容**：支持鼠标、触屏、物理字母键，以及 Tab 聚焦按钮后 Enter/空格激活；手机布局自动收缩

## 使用

```
直接用浏览器打开 index.html（无需服务器、无需构建）
或运行 start.bat（Windows）
```

每日密钥在「每日密钥设置」卡片中配置，点「应用并复位」后生效。表单中未应用的修改会显示提示，逐键操作、机器标签和整段处理始终使用已应用密钥。

- 应用成功会复位转子、清空逐键记录、熄灭灯板，并清除旧批量结果。
- 应用失败保留原机器和逐键状态，清除旧批量结果，显示错误。
- 手拧转子只改变逐键机器的位置；整段操作仍从已应用的起始位置开始。
- 修改整段输入后，旧结果立即清除；没有有效结果时不能复制，复制失败不会显示“已复制”。
- 只处理 ASCII `A–Z/a–z`，其余字符忽略。解密不能恢复空格、数字、标点、中文或德语变音字母；必要时先自行转写。

## 验证

核心逻辑与界面解耦，测试使用 Node.js 18 或更高版本，无需安装依赖：

```
node selftest.js            # 核心：38 项断言
node --test ui-selftest.js  # 界面脚本：16 项回归测试
```

核心测试覆盖默认及非默认环设置的外部已知向量、双步进、反射板性质、长文本往返、非法配置抛错等：

- 默认配置（I-II-III / UKW-B / AAA / AAA / 不插线）连按五次 A → **BDZGO**（维基百科收录向量）
- 双步进锚点：`ADU → ADV → AEW → BFX → BFY`
- 450 次抽样加密中 0 次字母加密成自身
- Py-Enigma 文档向量：II-IV-V / B / 环 BUL / 10 对插线，起始 WXC 时 `BLA → KCH`，以及完整消息向量

界面脚本测试在最小 DOM 中执行真实 `enigma-ui.js`，覆盖草稿与已应用设置、批量结果失效、非主鼠标按键、文本输入保护、复制失败和异步复制反馈等。它不替代浏览器中的原生触屏、键盘激活和视觉排版验收。

GitHub Actions 在 push 和 pull request 时自动运行两组测试。

## 背景

恩尼格玛本质上是一台多表代替密码机：插线板 → 三个转子正向 → 反射板 → 三个转子反向 → 插线板。它的结构特性和历史操作规程曾被用于密码分析；现代计算机也能辅助搜索和分析。实际破解耗时取决于密文长度、已知明文、密钥范围、算法和硬件，不能统一断言“几秒即破”。本工具用于历史学习和实验。
